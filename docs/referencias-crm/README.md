# Referencias de estilo para el CRM

Capturas que se tomaron como guía para el CRM de Pehn (26 oct 2026). Todavía falta decidir si el CRM se queda en Apps Script o se hace aparte; mientras tanto, el estilo ya se aplicó a `apps-script/Admin.html`.

- `synergy-task-list.png`: tabla limpia dentro de una tarjeta, con encabezado ("Task List" + ordenar/filtrar), estado en píldora con punto, barra de avance, avatares y paginación numerada ("1 2 3 … 10" + "Mostrando 1 a 8 de 50"). Cifras arriba con icono a la derecha y píldora de variación (+12%).
- `emas-dashboard.png` y `emas-master-laporan.png`: menú lateral oscuro café con secciones ("MENU UTAMA"), tarjeta del usuario abajo, bienvenida con degradado cálido y botones rápidos, tarjetas de cifras con fondo de color suave (crema, menta, lila, cielo, rosa), botón principal dorado.

## Qué se tomó para Pehn

| Elemento | Cómo quedó |
|---|---|
| Menú lateral | Café oscuro `#211812`, activo con borde naranja Pehn, secciones *Menú principal* y *Accesos*, tarjeta del negocio abajo |
| Barra superior | Blanca, icono de la vista + nombre, buscador global, botón de actualizar |
| Encabezado de vista | Título, una línea de resumen y la fecha de hoy |
| Inicio | Saludo con degradado crema/naranja, resumen del día y botones rápidos (dorado = principal) |
| Cifras | Tarjetas con tinte (brand, lila, menta, cielo, rosa), icono arriba a la derecha y píldora de % contra el mes pasado |
| Tablas | Dentro de un panel con título, contador, buscador y filtros; encabezado sin mayúsculas; flechas de orden |
| Estados | Píldora con punto de color (también en el selector de la tabla) |
| Pedidos | Avatar con iniciales del cliente, columna *Avance* (porcentaje según el estado), paginación numerada |
